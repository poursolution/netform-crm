## Safe local fragment

Only O03 has a single evidenced current contract. `adapter-contract.js` mirrors its exact input conversion and storage key, but is intentionally not wired into UI or Supabase. The read-only Staging preflight also proves that `public.dashboard_state` is not a safe compatibility target: its current policy and grants do not encode actor scope or shared-versus-personal ownership. Keeping O03 local preserves the current meaning and prevents accidental treatment as an organization-wide goal.

There is deliberately no SQL implementation. `candidate.sql` and `rollback.sql` are no-op markers. Adding any server object from the old candidates would invent current tables, permissions or business semantics. Frozen work/direct-assign logic and the public `crm_write_command_v2` are untouched.
