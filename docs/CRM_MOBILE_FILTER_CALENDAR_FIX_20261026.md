# 모바일 내 현장 필터·일정 기간 수정 (2026-10-26)

상태: 로컬 구현·합성 브라우저 검증 완료. 운영 배포 전입니다.

## 바뀐 동작
- 내 현장 필터 버튼에서 브랜드·단계·진행 중 조건을 함께 선택합니다. 검색어도 함께 적용합니다. 현재 계정의 myDeals/PipelineScope 범위 안에서만 고릅니다.
- 적용할 때 목록 1쪽·맨 위로 이동합니다. 취소·닫기·Escape·뒤로가기는 초안만 버립니다. 초기화도 적용 전에는 기존 조건을 바꾸지 않습니다. 위쪽 단계 칩과 같은 상태를 씁니다.
- 계정·세션이 바뀌면 필터 초안과 이전 조건을 폐기합니다. 오래된 창의 적용은 무효입니다. 배경은 inert 처리하고 초점을 창 안에서 순환·복귀시킵니다. 일반 화면 갱신에도 초안과 활성 입력 초점을 유지합니다.
- 일정 제목·연락 지표·빈 약속 지표의 설명이 선택한 지난주/이번 주/다음 주와 일치합니다. 완료 판단·분자·분모·저장 산식은 유지합니다.

## 디자인과 파일
필터 디자인은 사용자가 승인한 Claude 설계입니다. 실제 승인 B/C 원본의 검정 칩·글꼴·최대 480px 셸을 대조했습니다. 모바일 승인 화면 원본과 기존 왼쪽 AI 사무실 화면은 수정하지 않았습니다.

기능: mobile-mine-filter-model.js / mobile-guide-shell.js. 디자인: mobile-approved-mine-filter.js / mobile-approved-mine-filter.css. mobile.html에서 이 파일들을 로드합니다. 일정: mobile-schedule-model.js / mobile-approved-f.js.

## 검증
- 관련 모바일 검사 152개 통과, 실패 0개(기존 131 + 일정 9 + 필터 12). 문법·실제 디자인 render 특수문자 처리 검사도 통과했습니다.
- CUA 브라우저에서 20건 쪽 이동 후 적용 시 1쪽 복귀, 조건 조합 2건, 검색 조합 1건, 초기화 후 취소, Escape, 뒤로가기, 재표시 초점, 계정·세션 변경을 확인했습니다.
- 실제 iframe 320/360/390px에서 100자 합성 브랜드 줄바꿈·가로 넘침 없음, 조작 영역 44px 이상을 측정했습니다. 합성 자료와 실제 수정 셸/모듈을 사용했으며 운영 고객 저장 검사는 아닙니다.

## 남은 범위
- 실제 휴대폰 장치와 운영 서버 저장·발송은 이번 조회 전용 필터/문구 변경 검증 범위 밖입니다. 운영 반영 후 같은 조회 동선을 다시 확인해야 합니다.
- 수동으로 닫으면 다른 주소를 자동으로 뒤로 보내지 않도록 원래 history.state를 복원합니다. 같은 주소의 기록 한 칸이 남을 수 있고 다음 열기에서 재사용합니다. 기록 API를 사용할 수 없으면 안내 후 취소/닫기로 계속 사용합니다.
- 관리자 내 담당/팀 전체 조회 범위, PC 활동 이력의 내부 값 표시는 이번 수정에 포함하지 않았습니다. 기존 SQL 수정과 다른 작업 파일도 보존했습니다.
