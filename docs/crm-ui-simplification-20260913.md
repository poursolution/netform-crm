# CRM 실행화면 정리 — 2026-09-13

> 아래는 1차 작업 시점의 기록이다. 후속 구현·검증·잔여 범위는 [최종 UI 릴리스 검증](detail-workspace-release-20260913.md)을 기준으로 확인한다.

사용자 첨부 검토문은 `90a5cfa` 기준이며 이번 작업의 기준 커밋은 `242995b`다.
최신 요구인 **오늘업무 단일 실행 목록**이 이전의 관리자 2개 게시판 요구를 대체한다.
DB 구조·담당자 원본·배정 RPC·n8n·잔디·구글시트는 이번 UI 작업 범위에서 변경하지 않는다.

## 1차 로컬 구현

| 화면 | 변경 | 확인 방법 |
| --- | --- | --- |
| 오늘업무 | 관리자 2개 게시판을 단일 표로 통합. 견적문의/파이프라인/관계관리/확장관리 구분. 상태·담당자·유형·검색 복합필터, 20건 숫자 페이지 | `verify-today-queue-browser.cjs` |
| 오늘업무 | 동일 관계관리 Deal 이중집계 제외. 확장 전환완료·보류 제외. 직접 입력하지 않은 확장 연락일은 계산 일정으로 표시 | 위 테스트의 가상 데이터 |
| 오늘업무 | 배정 버튼 유지. 상세는 인덱스 대신 원본 ID로 재확인. 역할 변경 후 다른 담당자 항목 열기 차단 | 위 테스트 및 `verify-inquiry-unassigned-browser.cjs` |
| 견적문의 | 기본 행을 6열로 그룹화. 공종/상담담당은 현장 보조정보. 1,400px 강제 폭을 기본 목록에서 해제 | `verify-inquiry-role-view-browser.cjs` |
| 견적문의 | 기본 상태 4개. 상세보기·지역·중복·휴지통·대량처리는 접히는 관리도구. 기존 핸들러/저장 경로 유지 | 역할별 회귀 테스트와 배정 테스트 |
| 관계관리 | 업무함·담당자 예외·상세·20건 페이지는 `242995b`에 이미 반영. 이번에는 다시 만들지 않음 | 기존 관계관리 브라우저 테스트 |

확장관리 연락 일정은 기존 풀에서 읽기만 한다. 오늘업무를 그릴 때 자동화나 메시지를 실행하지 않는다.
미배정 여부는 기존 공통 배정 판정에서 가져오며 새로운 배정 추정값을 저장하지 않는다.
숫자 필터는 같은 목록에서 계산하며 중복될 수 있는 지표임을 표시한다.
일반 영업사원은 본인 범위만 대상으로 상단 우선순위와 하단 오늘 예정 업무를 중복 없이 나눈다.

## 남은 작업 — 완료로 간주하지 않음

1. P1 영업사원 관리: `paintRepManagement`의 흐름/코칭/실행/업무량을 개입 목록 + 상세로 재구성.
2. P2 공통 상단: 견적문의의 기간·담당자 필터는 높이만 줄였다. 모든 운영 메뉴의 단일 필터줄 전환은 미완료.
3. P2 파이프라인: 상세는 보존하고 기간/담당자/사업유형/보기 상단을 정리. 역할별 기본 보기 검토.
4. P2 확장관리: `ExpansionPool.render`의 소개/KPI/담당자표 축소. 목록 기본화. ‘관계관리→유지접촉’은 이번 오늘업무 표시에서만 적용했으며 풀의 상태값·UI 전체 명칭은 아직 그대로.
5. P2 고객자산: `CUSTOMER ASSET MASTER` 영역 축소, 상세 탭/앵커 구성.
6. P2 문자발송: ‘문자·캠페인’ 명칭과 대상→문구→미리보기→발송 중심 메뉴 구성.
7. P2 경남지사: 인계 미처리 목록 우선 배치. 분석 영역은 하단으로.
8. P2 대시보드/실적/KPI: 오늘 처리·사람 관리·프로세스 관리·실적 조회의 중복 영역 분리.
9. 보고/주간브리핑/공종분석/데이터 정리는 최소 변경 대상으로 유지.

## 확인 범위와 남은 위험

- 1차 자동검증: 610건 중 594 PASS, 0 FAIL, 16 SKIP. 건너뛴 환경 의존 테스트를 통과로 계산하지 않는다.

- 브라우저 테스트는 localhost와 가상 데이터로 실행하며 외부 요청을 차단한다. 실제 고객 문자/배정/영업 상태를 변경하지 않는다.
- 기존 오늘업무의 최근 14일/30일 등 일부 신호 산정 기준은 이번에 새로 정한 기준이 아니며 기존 규칙을 보존했다. 실제 운영 대상 완전성 검토는 별도 필요하다.
- 관리자·영업사원 UI 분기는 기존 role 판정을 따른다. UI 분기가 서버 권한 검증을 대체하지 않는다.
- 신규 통합 목록의 클릭 대상/역할/필터를 검증했지만 모든 실제 계정의 서버 저장을 검증했다고 주장하지 않는다.
- 이번 신규 UI는 로컬 변경이며 운영 배포 전이다. 운영은 `242995b`다.
