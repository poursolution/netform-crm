# 상세화면 후속 정리

## 변경 / 근거

- 문의 스플릿 상세에 고객 원문·문의자·연락처·공종을 진행바보다 먼저 표시. 원문을 Deal에서 추정하지 않고 HTML escape한다.
- 파이프라인 인계 영역의 두 번째 진행선을 제거. 기존 상단 단계 표시와 인계 기능은 유지한다.
- 빠른상세의 정규식 기반 버튼 제거를 `splitInlinePanel(d, hideActions)` 옵션으로 교체. 같은 동작 버튼을 두 번 생성한 뒤 지우지 않는다.
- 브라우저에서 빠른상세 단계 변경 클릭 후 `inlineTransition`이 생성되지만 숨겨지는 문제를 재현했다. 기존 `openFullDealFromQuick()` 경로로 상세를 연 뒤 단계 전환을 열도록 수정했다.

## 검증

- 문의 관리자/직원 범위, 문의 원문이 진행바보다 앞에 있음, 진행바 1개, 원문 HTML 비실행을 localhost 브라우저에서 검증.
- 빠른상세 활동/다음 행동 버튼 각 1개 → 입력폼 각 1개 → 닫기, 단계 변경 버튼 1개 → 보이는 전환창 1개 검증.
- 상세 기존 18개 활동 필터, 5개 탭, 8개 Next 유형, 즐겨찾기, 초안/스크롤 유지 및 62개 연결 버튼 회귀 검증.
- 고객자산 6개 탭/복귀, 관계관리 기록창/초안, 담당자 4개 탭, 메뉴 15개 이동, 모바일 가로폭 검증.
- 합성 데이터·외부 네트워크 차단. 실제 저장/RLS E2E 완료 주장은 하지 않는다.

## 경계 / 남은 일

이번 후속 UI 변경은 DB와 외부 시스템을 변경하지 않는다. 앞선 412행 보정은 별도 승인·기록 건이다.
관계관리 통합 저장, 기존 활동을 전환 근거로 재사용하는 서버 계약, 전체 renderDetail 래핑 정리는 미완료다.
동일 문의인지 불명확한 중복 후보는 병합하지 않았다.
