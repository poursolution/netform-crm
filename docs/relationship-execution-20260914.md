# PC 관계관리 — 관리계획과 실행

- 목록 순서를 고객/담당자 → 관리 목적/예상 공사 → 이번에 할 일 → 예정일 → 최근 대화 → 실행으로 변경.
- 이번 할 일 강조, 막연한 연락/확인 및 미입력은 구체화 안내와 관리계획 작성 버튼. 기존 값을 추측하여 변경하지 않음.
- KPI: 오늘 연락, 이번주 예정(오늘부터 일요일까지), 다음 일정 없음, 기한초과. 90일 미접촉은 기존 최근 접촉기간 필터에서 유지.
- 기존 통합 연락 기록창에 결과 선택, 관리계획 예시, 7/14일·1/3개월 바로가기 추가. 응답 없음 선택은 실제 연결 체크 해제. 실제 연결 여부는 사용자가 확인.
- 결과 선택만으로 Pipeline 전환/종료/공사연도 수정은 하지 않음. 기존 관계관리 통합 저장 계약 그대로 사용.
- 브라우저 회귀 PASS: 필터, 계획 입력, 결과 선택, 원래 저장 연결, 역할 범위, 고객발송 대상, 1920/1440/1024px 가로 넘침 없음. 합성 화면 시각 확인 완료.
- 모바일 파일/공유 저장 어댑터/DB 스키마 변경 없음. SMS 비밀키 작업은 별도이며 이번 릴리스에 포함하지 않음.
