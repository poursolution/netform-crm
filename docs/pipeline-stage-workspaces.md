# 파이프라인 단계별 업무 화면 — 2026-09-20

상태: 로컬 구현·검증 완료, PR #112 반영 중. 운영 배포는 해당 PR 병합 후 확인한다.

## 화면 구성

- 컨설팅: 실제 요구사항/견적 요청과 견적 예정일의 등록 상태로 업무를 분류한다. 존재하지 않는 현장진단 완료 여부를 추정하지 않는다.
- 자료 발송완료: 후속 확인일을 기준으로 초과/오늘/미지정/예정 업무를 나누고 발송일·자료·반응을 표시한다.
- 관계관리: 마지막 유효접촉과 경과일을 중심으로 정렬하며 연락 기록을 기존 입력창으로 연결한다.
- 경쟁·임박·입찰: 결정 예정일의 지난 일정/7일 이내/이후/미등록 타임라인을 표시한다.
- 계약·시공: 계약 상태, 계약 원장 확인 여부, 고정 실적 귀속자, 착공 및 인계 정보를 표시한다. 체결 완료 문자열만으로 실적 확정을 표시하지 않는다.
- 수주: 조회월의 공통 계약 원장 집계와 담당자별 실적을 표시한다. 현재 단계와 무관한 계약실적이며 공종·현장 검색은 아래 수주 현장 목록에만 적용한다. 원장 조회 실패를 0원으로 표시하지 않는다.
- 실주: 조회월의 실주금액·사유 분포·경쟁사·재접촉 검토 정보를 표시한다. 실주일 없는 기록은 별도 확인 대상으로 보존한다.
- 확장관리: 메뉴는 파이프라인 아래에 두고 기존 expansion 페이지 및 ExpansionPool 렌더러를 직접 연다. 기존 연도·담당자·상태·접촉일 필터, 보드/목록, 우선순위 정렬과 독립 관리창을 그대로 사용한다.

전체 파이프라인 하위 버튼은 제거했다. 상위 파이프라인을 누르면 전체 목록으로 돌아간다. 전용 단계에는 공통 4개 KPI와 공통 상태칩/표를 반복하지 않는다. 전용 렌더러가 로드되지 않으면 명시적 재시도 안내를 표시한다.
