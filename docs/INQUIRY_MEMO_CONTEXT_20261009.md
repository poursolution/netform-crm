# 이관 메모 문맥 보존 후속 수정

PR #532 운영 대조에서 남은 날짜·방문 조건·현장 미팅 후보를 보완한다. 디자인, CSS, 배치, 새 화면, SQL, RPC, 운영 원자료는 변경하지 않는다.

- `[2026. 1. 7. 오후 5:06:44]` 안의 점을 문장 경계로 자르지 않는다. 원문과 강조 위치는 유지한다.
- 바로 앞줄이 `시간이 맞으면` 등 조건으로 끝날 때 방문 후보의 근거 문장에 함께 보존한다. 빈 줄이나 문장 종료를 넘어 다른 기록의 조건을 붙이지 않는다.
- `현장 미팅 후 … 연계 진행 예정`을 담당자가 확인할 후보로 읽고, 실제 이행 여부를 질문한다. 미팅 완료·취소·확인 필요만으로 약속을 만들지 않는다.
- 기존 문장 분할로 생성했던 판단 키를 유지해 이미 저장한 완료·미완료 판단이 분리되지 않게 한다.

검증: 단위 검사 15개 및 외부 요청을 차단한 localhost 브라우저 검사 통과. 실제 운영에서 확인한 줄바꿈을 합성 원문에 재현했다. 날짜 보완·고객 상태·후속 업무를 자동 저장하지 않는다.

남은 범위: 공식 첫 연락 판정과 이관 검토 상태 위치, 저장 실패의 로컬 잔존, 여러 약속의 기한 보존, 오래된 요청 재전송은 별도다. 새 표시 위치가 필요한 사항은 Claude가 결정한다. 이 문서는 운영 배포 완료를 의미하지 않는다.
