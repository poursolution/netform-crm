# Claude 인수인계 — 이관 통화 검토 분류 연결

대상: 영업운영 CRM `poursolution/netform-crm`. 현재 화면 위치·디자인은 유지한다. Codex는 CSS·HTML 배치·탭을 수정하지 않았다.

## 확인된 원인

PR #533 배포 후 신영프로방스 원문에서 2026-01-16 통화 후보와 현장 미팅 후 연계 예정을 읽지만, 목록은 여전히 ‘첫 연락 전’으로 표시한다. `inquiry-list-v3.js model()`은 `x.first`가 없으면 `step=1`로 정하고, `inquiry-v4.js ext()/lines()`가 신규 첫 연락 기한으로 안내한다. 메모 후보를 실제 연결로 자동 확정하는 방식으로 해결해서는 안 된다.

## 준비한 읽기 전용 함수

`InquiryMemo.contactReview(q)`:

```js
{
  required: true,
  reason: 'memo_call_unconfirmed', // 또는 copied_received_date
  candidateDate: '2026-01-16',    // 날짜를 읽지 못했으면 빈 문자열
  calls: [{ key, date, sentence, phrase, memoAt }]
}
```

- 실제 연결 없음 + 메모 통화 후보 있음 → `memo_call_unconfirmed`.
- 실제 연결일이 접수일 복사로 판정됨 → `copied_received_date`.
- 기존 연결 판정이 확인됨 또는 보완됨 → 검토 필요 아님.
- 부재·통화 예정만 있는 경우, 원문 없음, 기능 꺼짐은 검토 후보를 새로 만들지 않는다.
- 이 함수는 조회만 한다. 고객 상태·첫 연결 시각·성과·담당자·다음 업무를 저장하지 않는다. 반환된 후보 목록을 수정해도 원문/파서 캐시에 영향이 없다.
- **아직 목록·집계에 연결하지 않았다.** 이 함수를 배포해도 신영프로방스 ‘첫 연락 전’ 표시는 저절로 바뀌지 않는다. 이번 PR이 분류 문제 전체를 해결했다는 뜻이 아니다.

## Claude에게 필요한 결정과 연결 조건

‘이관 기록 확인 필요’ 대상을 현재 디자인 어디에서 관리할지 정하고 Codex에게 연결 위치를 알려준다. 새 탭·배치·색상은 Codex가 제안하거나 추가하지 않는다.

1. 전체 진행 목록에서 누락되지 않아야 한다. 첫 연락에서 빼기만 하거나 연락처가 있는 고객을 연락처 보완으로 보내면 안 된다.
2. 메모 후보만으로 후속 연락 완료·정상 진행·첫 연락 성과로 산입하지 않는다. 담당 미지정이면 담당 지정 업무가 우선이다.
3. 목록 v4, 끄기 뒤 v3/v2, 전체 상세, 오늘 업무, 영업사원 관리, 주간 브리핑, KPI의 대상 정의를 함께 연결한다. 총 대상 = 확인된 분류 + 검토 대상이 맞는지 검증한다.
4. 표시 문구는 후보/확인 필요를 유지하며, 검토 중인 과거 날짜로 수백 일의 신규 지연 평가를 만들지 않는다. 날짜 없는 후보도 남긴다.
5. 실제 새 연결 기록 또는 서버 보완 저장 성공 후에만 검토 대상에서 해제한다. 기존 로컬 낙관 저장/실패 복구 문제는 후속 수정이 필요하므로 서버 저장 완료와 로컬 표시를 혼동하지 않는다.

## 같은 PR의 기능 수정 — 약속 기한 보존

과거 약속을 ‘미완료’로 판단할 때 기존 미래 다음 행동일을 오늘로 바꾸던 오류를 수정했다. 과거/미래 기한 모두 유지하며 두 번째 약속을 추가해도 기존 업무 문구·기한을 유지한다. 합친 문구가 500자를 넘으면 기존 기록을 잘라내지 않고 저장 전 오류로 안내한다. 완료/확인 불가는 기존처럼 기록만 남긴다.

SQL·RPC·서버 칸 추가 없음. 운영 원자료 변경 없음. 캐시 태그만 변경하고 기존 화면을 그대로 쓴다.

## 검증 및 남은 범위

`node --test tests/inquiry-memo.test.cjs tests/inquiry-memo-followup.test.cjs`: 25개 통과. `scripts/verify-inquiry-memo-browser.cjs`: 외부 통신을 차단한 localhost 합성 데이터 검사 통과. 실제 고객에게 테스트 저장하지 않았다.

남은 기능: 서버 거부 시 낙관적 로컬 판단이 남는 문제, 오래된 요청 재전송의 역전 방지, 검토 상태의 전 화면 연결. 이 문서는 이 항목의 배포 완료를 뜻하지 않는다.
