## 3. 대표 결정이 필요한 것
1. 영업건 상세(C) 체크리스트를 위로 올릴지(승인 원본 10/11 과 8/27 회의록이 다름).
2. 오늘 화면을 v5 한 줄 큐(10/20 결정)로 둘지, 3덱(연락 · 방문 · 기한 초과)으로 바꿀지.
3. 모바일 내 현장 · 오늘에 PipelineScope(과거 이관 제외)를 적용할지.
4. 상세 하단 고정 [전화] [다음 단계] 바 · 4단계 진행 바 — 승인 시안 변경 여부.
5. 견적 작성을 모바일에서 뺄지(PC 전용).
6. PWA 홈 화면 아이콘(이름 · 아이콘).
7. 간편 로그인(이름 + 휴대폰) — 현재 안내문과 반대.

## 4. Codex(서버 · 데이터)로 넘길 것
1. '지원 업무 종결' 종료값(SQL enum/제약 + 집계 분모 영향 — 메이드율은 수주 ÷ (수주 + 실주) 유지).
2. 모바일 오늘 큐 경량 조회 함수(담당자 · 기한 ≤ 오늘 · 20건) — 지금은 전체 수신.
3. 과거 이관 정체 데이터 격리(서버 쪽 PipelineScope 와 같은 기준) · 360건 아카이브.
4. 음성 메모 구조화(crm-ai: 핵심 이슈 · 경쟁사 · 다음 행동 · 기한).
5. 하자 사진 간이 접수(표 · 저장소 · 하자 대시보드 웹훅).
6. 잔디 · 알림톡 인터랙티브 버튼 → 서버 반영.
7. 브랜드별 공식 채널 발신 분리(9/9).
8. 관리자 계정 제어 메뉴(10/1) — 직원 계정 관리 v2 에 삭제 · 외부 이사 등록 범위 확인.
