## 이번 기능 수정

- `2026/01/16 PM 05:02`처럼 날짜·시간만 적힌 윗줄 바로 다음의 `1차통화완료`를 날짜가 있는 통화 후보로 읽는다. 후보 발견은 실제 연결일 확정이나 첫 연락 지표 변경이 아니다.
- 사진·도면 전달에서 `보내주신다`는 고객 → 담당, `드리기로`는 담당 → 고객으로 구분한다. 주체가 분명하지 않은 표현은 `전달 여부 확인`으로 남긴다.

- 기존 공유 모듈 `inquiry-memo.js`만 수정하고 `crm.html`의 해당 캐시 키를 갱신했다. 서버 함수·SQL·권한·자동 발송·n8n 변경 없음.
