## 검증

- 재현 자료에서 1.3 → 33.3은 +32.0%p, 10.6 → 100은 +89.4%p. 주간 저장의 분자·분모도 동일.
- 156건 = 등록 26 + 미등록 130. 요청 가능 129 + 담당 없음 1 = 130.
- 예전 담당자 묶음 요청이 있는 경우 요청 가능 104 + 이미 요청 중 25 + 담당 없음 1 = 130.
- 전년도 생성 진행 건 포함, 개인 권한 유지, 브랜드 선택·휴지통·협약문의·과거 이관 제외, 전주 접수/이번 주 배정 및 배정 전 응답 시각 검증.
- 관계관리 미분류·미확인 제외 및 측정 가능한 대상 0건 처리 검증.
- 기존 KPI/오늘 업무 관련 Node 검사와 로컬 브라우저 기능 검사 통과. 합성 자료이며 운영 건수로 사용하지 않는다.

## 운영 반영 후 확인

1. 같은 계정·담당·브랜드·공종·검색에서 오늘 업무와 KPI의 다음 행동 분자·분모를 대조한다.
2. 운영 화면의 현재값·지난주 저장값·증감과 요청 가능/기요청/담당 없음 합계를 대조한다.
3. 과거 주간 저장본은 당시 기준으로 남아 있다. 증감 산술은 바로잡지만 과거 기록을 새 산식으로 임의 덮어쓰지 않는다.
4. 실주에서 사유가 인정된 1건, 계약정보 누락의 전체/오늘 대상 차이, 관계관리 미확인 대상을 실제 목록으로 확인한다.
