## 추가·바꾼 데이터 필드

서버 필드·권한·금액·단계·업무·요청 변경 없음. 기존 탭 범위 미전송 초안에 로그인 세션과 견적 근거 지문을 함께 보관한다. 마지막 성공한 보관 후 30분까지만 복구한다. 선택값은 고객 약속·견적 접수·발송·고객의 안 선택을 확정하는 데이터가 아니다.

이전 형식 초안에 로그인 세션·근거가 없거나 원문이 손상되면 빈 초안으로 덮지 않는다. 영업건 버전이 달라진 초안도 자동 재적용하지 않는다. 회사·동일인 선택 등 명함의 미확정 기준은 이번 범위와 무관하며 그대로 남겨 둔다.

## 서버 연결과 PC와 다른 점

2026-10-11 운영 프로젝트의 `pg_proc`/`pg_namespace`만 읽어 재확인한 결과, public·crm_security에 아래 네 함수가 없었다. 고객 행 조회·함수 실행·SQL 설치는 하지 않았다.

- `crm_quote_compose_v1`
- `crm_cost_standard_list_v1`
- `crm_quote_version_save_v1`
- `crm_quote_submit_confirm_v1`

따라서 공통 계산 연결·수정본 저장을 켜지 않았다. 모바일 계산을 추가하거나 저장 함수를 미리보기용으로 부르지 않는다. 현재 PC는 기준 조회 뒤 로컬 계산을 쓰므로 사용자 지정 ‘양쪽 같은 서버 계산’까지 충족한 상태는 아니다.

## 질문 / Claude 인수인계

새 디자인 결정은 없다. 기존 원가계산서 행을 원본대로 복원했다. 서버에서 먼저 정리할 것은 계산 조건 이어받기, 직접공사비 합계 반환, 초안 권한, 저장 전 계산과 저장 시 기준일 일치다. [Claude 서버 계약 인수인계서](CLAUDE_QUOTE_MOBILE_SERVER_CONTRACT_20261011.md)에 정확한 함수·입력·미구현 부분을 갱신했다. 문서 작성은 Claude에게 전송하거나 운영에 설치했다는 뜻이 아니다.
