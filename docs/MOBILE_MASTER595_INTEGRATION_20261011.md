## 검증

별도 비교에서 다음을 확인했다.

- 후보 PC HTML에서 외부 스크립트 태그를 제외한 문서 내용은 #595와 동일하다. Claude 메뉴·레이아웃·스타일 변경 없음.

- 원가 기준 스크립트 2개와 후보 공통 일정 스크립트가 함께 로드된다.

모든 브라우저 검사는 합성 사용자·RPC 응답을 사용한다. 실제 운영 권한·원가 데이터·서버 설치·고객 저장의 검증 결과가 아니다.
