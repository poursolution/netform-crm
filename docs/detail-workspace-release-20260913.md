# CRM 실행화면·상세 정리 — 2026-09-13

## 범위

첨부된 전체 화면·상세화면 검토와 후속 진행 요청에 따른 UI 릴리스다. 기준 커밋은 `242995b`. Production DB/RPC, 기존 문의 담당자·금액·상태, n8n, 잔디, 구글시트는 변경하지 않는다. 실고객 문자 발송이나 테스트 영업활동도 실행하지 않는다.

## P1 문제 → 근거 → 수정

| 문제 | 발견 근거 | 수정 |
|---|---|---|
| 문의를 열었는데 별도 영업기회가 열림 | 현장명 fallback + 문의/Deal 자동 전환 | 문의 ID 유지, 검증된 명시적/유일 역참조 연결만 별도 열기. 충돌·잘못된 기존 연결에서는 신규 전환 차단 |
| 금액 저장 거절 전에 화면만 변경 | 기존 saveBasics가 adapter 응답 전에 객체·로컬값 변경 | 예상금액만 편집, 견적/수주 읽기전용. 정확한 queue ACK 확인 후 반영. 거절·불확실·중복·저장 도중 이동 보호 |
| 미전환 문의에 Deal 저장폼 노출 | 합성 데이터에서 금액 필드 3개 확인 | 문의 전용 읽기 상세와 기존 문의 처리 화면으로 분리 |
| 전환 작업 종료 후 버튼이 안 움직임 | 새 집중 화면에서 legacy closeTransition 호출 시 표시 모드 잔존 | 공통 닫기에서 구조화 전환의 상태·표시·포커스까지 함께 종료 |

## 화면 변경

- 오늘 업무: 관리자 단일 실행 목록, 영업사원 본인 우선순위/오늘 업무 분리. 견적문의·파이프라인·관계·확장, 같은 데이터로 카운트/복합필터/20건 페이지.
- 견적문의: 기본 6열, 관리도구 접기, 문의 원문 유지, 기존 문의 처리 버튼을 위로 이동. 문자열·객체형 원문 지원 및 HTML 이스케이프.
- Deal 개요: 최근 활동 중심, 체크리스트 접기. 연락처와 관계도는 활동 탭, 인수인계는 이력, 상세 상태정보는 일정으로 이동. 중복 관계도 출력 제거.
- 연락처: 보기/수정 분리. 노드를 복사하지 않고 이동하므로 기존 입력 ID·저장 경로 유지.
- 관계관리: 연락 기록/일정 등록은 간단 작업화면. 기존 활동·다음 행동 편집기 각 1개 사용. 전체 영업정보로 넓혀도 작성 중 초안 보존. 활동 저장과 다음 행동 저장은 **별도 작업**이며 통합 트랜잭션이라고 표시하지 않는다.
- 단계 전환: 현재 상세 안에서 전환 작업에 집중. 기존 활동/Next 참고 표시, 자동 활동 복제·증거 추정 없음. 기존 단계별 필수 검증 유지.
- 고객자산: 요약/진행영업/거래·공종/인물/활동/확장 6개 탭. 영업기회 종료 시 원 고객·탭·스크롤 복귀. 중첩 창 대신 한 창씩 전환.
- 확장관리: 관리자 기본 목록/직원 기본 보드, 담당자 집계 접기, 상단 소개 축소, 고객 연락처 상단 표시. UI의 관계관리 표시는 유지접촉으로 구분하되 저장 상태값은 보존. 창 포커스/Tab 순환 보완.
- 영업사원 관리: 관리자 개입 표 우선, 흐름·업무량·분석 접기. 담당자 상세는 현황/문제현장/활동/실적근거로 분리.
- 경남지사: 즉시 확인→본사 인계→접힌 흐름/분석 순서. 기존 집계·담당자 배정 기능 유지.
- 공통: 고객자산·확장·문자·영업사원 관리 소개 축소, 기간필터 설명 축소, 문자·캠페인 명칭 통일. 대시보드는 위험 참고+오늘 업무 링크, 담당자 실적의 실행관리 항목은 접기.
- 주간 브리핑·공종분석·대표보고·데이터정리의 원본 처리·안전 확인 절차는 변경하지 않음.

## 남은 위험 / 다음 우선순위

1. 실제 계정별 Production 저장/RLS 및 동시 수정 E2E는 미검증. 테스트 제외 16개를 PASS로 계산하지 않음.
2. 실제 미배정 문의의 시트→동기화→DB 대조는 이번 UI 릴리스에서 수행하지 않음. 관련 외부 시스템을 변경하거나 해결됐다고 주장하지 않음.
3. 기존 저장 작업 모두를 ACK 방식으로 재작성한 것은 아님. 이번 금액 저장 외 다른 작업은 기존 adapter/queue/권한 검증 경로 유지.
4. 새 레이아웃은 한 모듈의 명시적 훅으로 정리했으나 과거 renderDetail 전체 재작성·미사용 DCC 완전 제거는 회귀 위험 때문에 하지 않음.
5. 관계관리 활동과 다음 연락일의 단일 저장 버튼/원자적 저장, 모든 메뉴 단일 필터줄, 분석 지표 정의 재설계는 범위 확대이므로 미적용. 기존 데이터를 감추거나 추정하지 않음.

운영 릴리스의 정확한 소스 커밋과 런타임 해시는 `production-ui-manifest.json`에 기록한다. 로컬 candidate manifest는 배포 파일에 포함하지 않는다.
