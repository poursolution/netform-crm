01

견적문의 — 접수부터 정리까지

새 문의는 먼저 담당과 최초응대 상태를 확인합니다. 문의를 바로 영업기회로 보지 말고, 배정과 응대가 끝난 뒤 전환합니다.

왜 이 순서인가요?미배정 문의와 응대 지연을 먼저 없애야 고객 연락이 빠지지 않고, 이후 파이프라인 담당과 이력이 정확히 이어집니다.
목록 확인빠른 처리담당 배정최초응대영업 전환보류·정리
1

견적문의 메뉴에서 오늘 처리할 건 찾기

왼쪽 견적문의를 누른 뒤 상단의 미배정·최초응대 대기 수를 먼저 봅니다.

  1. 상태 카드에서 신규·미배정·배정완료를 선택합니다.
  2. 접수일, 현장, 공종, 상담담당, 영업담당을 확인합니다.
  3. 한 건은 행을 누르고, 여러 건은 체크박스로 선택합니다.
완료 확인 · 선택한 문의가 목록 하단의 처리 영역에 잡힙니다.
2

점 세 개로 작업 종류 선택

행 오른쪽의 ⋯을 누르면 상세, 상담담당, 배정, 보류, 중복, 휴지통 작업이 한 번에 보입니다.

  1. 정보를 먼저 볼 때는 상세 처리.
  2. 고객 상담 담당은 상담담당 지정.
  3. 영업 책임자를 정할 때는 영업담당 배정.
원칙 · 목적이 다른 버튼을 섞지 말고 필요한 작업 하나만 고릅니다.
3

상세에서 문의 내용과 연락처 검토

  1. 현장명·연락처·유입 사업유형을 확인합니다.
  2. 문의 공종과 고객 요청 내용을 읽습니다.
  3. 현재 담당, 응대 이력, 다음 행동을 확인합니다.
  4. 오류가 있으면 전환 전에 문의 정보부터 바로잡습니다.
완료 확인 · 누가, 어떤 문의에, 언제 연락해야 하는지 설명할 수 있어야 합니다.
4

최초 영업담당 배정

  1. 추천 표시와 진행 건수를 참고합니다.
  2. 담당자 행을 눌러 한 명을 선택합니다.
  3. 필요하면 배정 사유를 적습니다.
  4. 본사 영업담당 배정을 눌러 마칩니다.
완료 확인 · 목록의 영업담당이 선택한 사람으로 바뀌고 배정 시각이 표시됩니다.
5

재배정은 사유까지 남기기

  1. 현재 담당과 새 담당이 다른지 확인합니다.
  2. 새 담당자를 선택합니다.
  3. 지역·공종·업무량 등 실제 변경 사유를 입력합니다.
  4. 재배정 버튼이 활성화되면 저장합니다.
주의 · 사유 없는 재배정은 하지 않습니다. 이전 담당과 변경 사유는 이력으로 남습니다.
6

상담담당과 영업담당 구분

상담담당은 최초 상담·접수 운영을 맡고, 영업담당은 이후 영업기회를 책임집니다.

  1. 상담을 실제로 진행한 직원을 고릅니다.
  2. 상담담당 없음은 실제 미지정일 때만 사용합니다.
  3. 저장 후 최초응대 기록 유무를 확인합니다.
완료 확인 · 상담담당과 영업담당이 각각 올바르게 표시됩니다.
7

보류할 때 다시 볼 근거 남기기

  1. 고객 요청, 일정 연기 등 보류 사유를 구체적으로 씁니다.
  2. 가능하면 다시 확인할 시점을 함께 기록합니다.
  3. 보류 처리 후 활성 문의 집계에서 상태를 확인합니다.
보류는 삭제가 아닙니다. 다시 연락할 가능성이 있으면 휴지통 대신 보류를 사용합니다.
8

중복 문의는 원본을 먼저 정하기

  1. 현장명, 전화번호, 접수일을 비교합니다.
  2. 계속 사용할 원본 문의를 선택합니다.
  3. 새 정보가 원본에 반영됐는지 확인합니다.
  4. 중복 건만 중복 처리합니다.
완료 확인 · 동일 고객이 두 건의 활성 문의로 남지 않습니다.
9

정말 불필요한 건만 휴지통 이동

  1. 삭제 사유를 목록에서 고릅니다.
  2. 추가 설명이 필요하면 메모를 남깁니다.
  3. 영업기회와 연결된 문의인지 마지막으로 확인합니다.
  4. 휴지통으로 이동을 누릅니다.
주의 · 전환된 원본 문의는 이력 보호 대상입니다. 단순 정리 목적으로 완전삭제하지 않습니다.
02

파이프라인 — 매일 움직이는 법

카드는 보기만 하는 현황판이 아닙니다. 한 일을 기록하고, 다음 행동을 예약하고, 근거가 생겼을 때만 단계를 이동합니다.

핵심 운영 원칙활동 기록 → 다음 행동 → 단계 전환 순서입니다. 단계만 올리면 왜 바뀌었는지 알 수 없고 오늘 할 일에서도 빠집니다.
칸반현장 선택한 일 기록다음 행동공종·금액단계 전환
1

칸반에서 우선순위 찾기

  1. 연도·분기·담당자·공종 필터를 확인합니다.
  2. 다음 행동 없음, 기한초과, 장기정체를 먼저 누릅니다.
  3. 단계별 건수와 금액을 비교합니다.
  4. 작업할 현장 카드를 누릅니다.
완료 확인 · 선택한 조건과 현장 목록이 서로 맞습니다.
2

빠른 관리에서 현재 상태 읽기

  1. 왼쪽 목록에서 현장을 선택합니다.
  2. 오른쪽에서 현재 단계, 담당, 금액, 최근 활동을 확인합니다.
  3. 여기서 한 일·다음 할 일·단계 변경 중 하나를 선택합니다.
  4. 더 많은 정보가 필요하면 상세를 엽니다.
완료 확인 · 지금 할 작업 하나가 명확해집니다.
3

방금 한 일을 사실대로 기록

  1. 전화·문자·카카오·방문·견적 중 활동 유형을 고릅니다.
  2. 무엇을 했는지 적습니다.
  3. 고객 반응이나 결과를 적습니다.
  4. 실제 접촉이면 고객 접촉 체크를 유지합니다.
  5. 활동 저장을 누릅니다.
완료 확인 · 최근 활동 시각과 타임라인에 새 기록이 보입니다.
4

다음 행동과 기한을 함께 예약

  1. 전화·방문·자료 전달 등 행동 유형을 고릅니다.
  2. 실행 날짜를 선택합니다.
  3. 누가 읽어도 알 수 있게 행동 내용을 적습니다.
  4. 다음 행동 저장을 누릅니다.
완료 확인 · 대시보드 오늘 할 일과 현장 상세에 같은 내용이 표시됩니다.
5

빠른 단계 변경 전 필수값 확인

단계 변경은 현장 상태를 실제보다 앞서 보이게 만들 수 있으므로 활동과 근거를 먼저 남깁니다.

  1. 현재 단계와 이동할 단계를 비교합니다.
  2. 요구되는 금액·일정·사유를 확인합니다.
  3. 뒤로 가는 이동은 변경 이유를 구체적으로 씁니다.
단계를 먼저 바꾸고 나중에 기록하지 않습니다.
6

현장 상세에서 전체 맥락 확인

  1. 상단에서 현재 문제와 추천 행동을 봅니다.
  2. 개요, 공종·금액, 연락·활동, 일정·Next, 변경이력을 차례로 확인합니다.
  3. 연락처와 최근 고객 발언을 확인합니다.
  4. 하단 실행 버튼으로 필요한 작업을 엽니다.
완료 확인 · 활동·다음 행동·단계가 서로 모순되지 않습니다.
7

공종·금액을 각각 확인

  1. 공종·금액 탭을 누릅니다.
  2. 대표 공종과 전체 공종 조합을 확인합니다.
  3. 예상금액과 견적금액의 의미가 맞는지 확인합니다.
  4. 수정 전 기존 값과 근거를 확인합니다.
완료 확인 · 카드 요약과 상세의 공종·금액이 같습니다.
8

공종은 선택 → 대표공종 → 근거 순서

  1. 해당 공종을 하나 이상 선택합니다.
  2. 복합공종이면 대표 공종을 지정합니다.
  3. 저장 요약을 읽어 의도한 조합인지 확인합니다.
  4. 분류 근거를 적고 공종 저장을 누릅니다.
완료 확인 · 대표 공종, 공종 목록, 저장 요약이 함께 갱신됩니다.
9

단계 전환은 근거와 다음 계획까지

  1. 목표 단계를 고릅니다.
  2. 전환 사유와 근거를 입력합니다.
  3. 필요한 결과·금액·일정을 채웁니다.
  4. 전환 후 할 일을 확인합니다.
  5. 최종 확인 후 전환합니다.
수주·실주는 종료 결과입니다. 금액과 종료 사유를 다시 확인한 뒤 실행합니다.
10

새 영업기회 등록

  1. 아파트명과 공사명을 입력합니다.
  2. 공종·사업유형·담당자를 선택합니다.
  3. 금액, 관리사무소, 관리소장 연락처를 입력합니다.
  4. 현장 주소를 확인합니다.
  5. 등록 근거를 적고 영업 등록을 누릅니다.
완료 확인 · 새 현장이 초기 단계에 생성되고 담당자 목록에 나타납니다.
03

확장관리 — 수주 이후 다음 매출 찾기

완료된 거래는 그대로 보존하고, 재접촉 시점과 추가 니즈를 별도 목록에서 관리합니다.

파이프라인과 다른 점확장관리는 새 영업 단계가 아니라 기존 고객 관리 목록입니다. 새 견적이 실제로 생길 때만 새 영업기회로 전환합니다.
대상 확인다음 접촉일접촉·니즈견적 확인새 영업 전환
ⓘ

현재 조회 데이터에는 확장관리 대상이 없습니다.
매뉴얼을 위해 임의 고객을 만들지 않았습니다. 아래 화면처럼 대상이 비어 있는 것이 현재 실제 상태이며, 수주 완료 고객이 확장 대상 조건을 충족하면 카드가 나타납니다.

1

확장관리 목록을 여는 순서

  1. 왼쪽 확장관리를 누릅니다.
  2. 전체·관리대상·접촉예정·관계관리·니즈확인 상태를 확인합니다.
  3. 담당자 필터로 본인 고객을 좁힙니다.
  4. 대상이 생기면 다음 접촉일이 가까운 카드부터 처리합니다.
완료 확인 · 기존 수주 고객만 보이고 진행 중 영업은 섞이지 않습니다.
카드가 생기면 ①

기존 수주 공종·금액·준공일·당시 담당자를 먼저 확인합니다.

연락 후 ②

다음 접촉일과 상태를 바꾸고, 접촉 결과와 확인한 니즈를 기록합니다.

새 견적이 생기면 ③

실제 견적 발송 기록을 선택하고 새 영업기회로 전환합니다. 이전 수주 건은 그대로 둡니다.

  • 관리대상: 아직 연락 전
  • 접촉예정: 다음 연락일 확정
  • 관계관리: 대화 진행 중
  • 니즈확인: 추가 공사 요구 확인
  • 보류: 재개 시점이 먼 고객
  • 전환 완료: 새 영업기회에서 계속 관리
04

문자발송 — 대상부터 결과 확인까지

문자를 먼저 쓰지 않습니다. 대상 조건과 수신 가능 여부를 확인한 뒤 문구를 고르고, 실제 치환 결과를 보고, 마지막에 즉시 또는 예약을 선택합니다.

왜 4단계인가요?잘못된 고객, 오래된 번호, 수신을 원하지 않는 연락처, 이름이 틀린 문구를 발송 전에 걸러내기 위해서입니다.
대상 선택문구 선택미리보기즉시·예약이력 확인
1

발송 목적과 대상 고르기

  1. 왼쪽 문자발송을 누릅니다.
  2. 영업단계·관계관리·시즌·재활성·기존고객 중 목적을 선택합니다.
  3. 담당자·사업유형·공종·지역·관계온도·최근접촉 필터를 적용합니다.
  4. 발송 가능 표시가 있는 연락처만 체크합니다.
  5. 자동 제외 사유를 읽고 선택 완료를 누릅니다.
완료 확인 · 관리 대상, 발송 가능, 자동 제외, 현재 선택 수가 맞습니다.
2

목적에 맞는 문구 선택·수정

  1. 제시된 문구 중 하나를 고릅니다.
  2. 실제 보낼 문장을 읽고 필요한 부분만 고칩니다.
  3. 고객호칭·현장명·담당자명·공종요약 변수를 확인합니다.
  4. 과장 표현이나 불필요한 광고 문구를 제거합니다.
  5. 개인화 미리보기를 누릅니다.
완료 확인 · 빈 문구가 없고, 변수 표기가 정확합니다.
3

고객별 치환 결과 확인

  1. 선택 인원과 실제 발송 가능 인원을 비교합니다.
  2. 고객명·현장명·담당자명이 자연스럽게 보이는지 확인합니다.
  3. 제외된 고객이 있다면 이유를 확인합니다.
  4. 이상이 있으면 대상 수정 또는 문구 수정으로 돌아갑니다.
  5. 문제가 없을 때만 최종 발송 설정으로 갑니다.
현재 화면처럼 실제 발송 가능이 0명이면 실행하지 말고 연락처·동의 상태를 먼저 확인합니다.
4

즉시 또는 예약 중 하나 선택

  1. 최종 대상 수를 다시 확인합니다.
  2. 지금 실행이면 즉시 등록을 선택합니다.
  3. 예약이면 날짜와 시각을 정확히 지정합니다.
  4. 중복 클릭하지 말고 완료 안내를 기다립니다.
  5. 실행 이력에서 결과를 확인합니다.
대상 수가 0명이면 버튼을 누르지 않습니다.
5

예약 실행 확인

예약 실행 탭에서 예정 시각, 목적, 대상 수를 확인합니다. 시각이나 대상이 잘못됐다면 실행 전에 수정하거나 취소합니다.

완료 확인 · 같은 목적의 예약이 중복으로 잡혀 있지 않습니다.
6

실행 이력에서 완료·대기·실패 확인

  1. 실행 일시와 작성자를 확인합니다.
  2. 대상 수와 완료 상태를 확인합니다.
  3. 실패가 있으면 번호와 제외 사유를 확인합니다.
  4. 고객 응답과 다음 행동 연결 여부를 봅니다.
완료 확인 · 고객별 활동 이력에도 같은 발송 기록이 나타납니다.
7

문구·자료 탭 활용

목적별 기본 문구를 미리 읽고 사용할 문구를 고릅니다. 현장 상황과 맞지 않는 표현은 발송 화면에서 수정합니다.

원칙 · 기본 문구는 출발점이며, 최종 문장은 담당자가 직접 확인합니다.
8

성과분석으로 후속 행동 정하기

  1. 발송 완료, 고객 응답, 다음 행동, 단계 전진을 비교합니다.
  2. 응답이 낮은 문구는 다음 실행에서 바꿉니다.
  3. 응답 고객은 파이프라인의 다음 행동으로 연결합니다.
완료 확인 · 문자 자체가 아니라 이후 영업 행동까지 이어졌는지 봅니다.
05

모바일 하단 메뉴 — 전 화면 안내

모바일은 역할 모드에 따라 하단 네 개 메뉴가 바뀝니다. 아래는 실제 화면을 탭 순서 그대로 배열했습니다.

공통 사용법하단 탭 선택 → 카드 선택 → 상세 확인 → 한 일 또는 다음 행동 저장 순서로 사용합니다.

내 영업 모드

1. 오늘기한초과·오늘 일정·새 문의를 우선 처리합니다.
2. 내 영업내가 맡은 현장을 단계·위험·다음 행동 기준으로 봅니다.
3. + 영업새 현장과 연락처, 공종, 담당 근거를 입력합니다.
4. 내 실적기간별 진행·수주·활동 결과를 확인합니다.

관리 모드

1. 관제전체 주의 건과 미배정·기한 문제를 빠르게 봅니다.
2. 파이프라인단계별·종료별·담당자별 현황을 내려가며 확인합니다.
3. 실적담당자별 실행과 결과를 비교합니다.
4. 리포트요약 지표와 기간별 흐름을 확인합니다.
상세

모바일 현장 처리 순서

  1. 내 영업 또는 관리 파이프라인에서 현장을 누릅니다.
  2. 현재 단계, 담당, 금액, 연락처를 확인합니다.
  3. 전화·문자 후 활동 결과를 기록합니다.
  4. 다음 행동과 날짜를 저장합니다.
  5. 근거가 갖춰졌을 때만 단계를 바꿉니다.
  6. 뒤로 가서 카드 요약이 갱신됐는지 확인합니다.
PC와 모바일 중 어느 화면에서 저장해도 새로고침 후 같은 값이어야 합니다.
06

PC 전체 메뉴 화면 모음

자주 쓰는 네 업무 외 보조 메뉴도 빠짐없이 현재 화면으로 정리했습니다. 이미지를 누르면 크게 볼 수 있습니다.

찾는 순서왼쪽 메뉴 선택 → 상단 기간·담당 필터 확인 → 표 또는 카드 선택 → 상세 확인.
대시보드오늘 우선조치부터 실행합니다.
고객 자산현장·사람·거래·관계 이력을 함께 봅니다.
영업사원 관리활성 담당자와 업무 범위를 확인합니다.
관리팀 KPI관리 지표와 주의 건을 확인합니다.
경남지사지사 문의·담당·진행 현황을 확인합니다.
주간 브리핑이번 주 계획과 위험을 정리합니다.
영업 대시보드기간·금액·단계 흐름을 분석합니다.
담당자 실적사람별 실행과 결과를 비교합니다.
공종 분석공종별 건수와 금액을 확인합니다.
리포트·대표 보고핵심 지표와 근거 목록을 확인합니다.
데이터 정리중복·누락 후보를 검토하되 원본 확인 후 처리합니다.
07

저장 전 마지막 확인

어떤 화면에서도 아래 여섯 가지를 지키면 이력과 다음 행동이 끊기지 않습니다.

  • 현재 현장·고객이 맞는지 확인
  • 담당자가 실제 책임자와 같은지 확인
  • 변경 전 값을 한번 읽기
  • 사유·결과를 구체적으로 기록
  • 다음 행동과 날짜를 함께 저장
  • 새로고침 후 같은 값인지 확인
